## 三个变量决定九成选择：机房、内存、磁盘流量

有个很典型的翻车案例：一位卖家买了台“国内优化线路”的 VPS 跑欧美站，英国客户打开要 4 秒，美国客户要 5 秒，转化率惨到他自己不想看。问题不在 VPS 本身，在于机房离客户太远。后来换到美国西海岸机房，Google PageSpeed 的海外评分从 60 分跳到 85。

机房位置之所以排第一，是因为它决定的是物理延迟，软件层面几乎优化不动。客户在纽约，服务器在洛杉矶，往返就是 70 毫秒起步；服务器在香港，同样一批客户要多等两百多毫秒。这个差距不会因为内存从 2G 加到 8G 而消失。

选机房的对应关系很直接：北美客户选洛杉矶、圣何塞、纽约；欧洲客户选阿姆斯特丹、伦敦、法兰克福；亚太客户选香港、新加坡、东京。做全球生意又只买一台，洛杉矶的综合覆盖最稳，剩下靠 CDN 补。

**内存是第二个决策点，也是最容易被误解的一个。** WordPress 加 WooCommerce 跑起来，1 GB 是真的很紧，只能跑一个干净优化的站，装几个重型插件就顶到天花板，不建议当长期生产环境；2 GB 才算起步勉强够用；4 GB 就舒服多了，图片多、插件多的店铺应该从这里起步。另一份口径更具体：日均一两千 PV，2 GB 内存配双核 CPU 就够，流量上来再升 4 GB，只有上了大促、多语言、插件堆一堆，才需要往 6 GB 以上走。

云厂商那边的建议会更保守一些：WooCommerce 建议 2 核 CPU、4 GB 内存起步，低于 2 GB 容易出现处理延迟，系统盘 60 GB 以上 SSD。这两个口径不矛盾，差别在场景：4 GB 是给商品多、插件多、活动频繁的店留的余量，2 GB 是给产品线干净、日 PV 四位数的店用的。如果你不确定自己属于哪种，按 2 GB 起步、留好升级路径，比一次买到 8 GB 更划算。

磁盘和流量是第三个变量。SSD 比 HDD 快不是一点点，尤其影响数据库读写，WooCommerce 的商品检索、库存校验、结账事务全是数据库操作。容量上，一个带几百张产品图的标准 WordPress 站，20–40 GB 基本够；40 GB 更稳，20 GB 只够一个干净小站，超大图建议传到 CDN 或对象存储，不要堆在服务器本地。月流量 2–3 TB 对中小独立站够用，超过这个量级再考虑不限流量的档位。

## 共享主机、轻量云、VPS 到底差在哪

**共享主机**便宜，但流量一上来响应就慢，邻居网站被攻击也会波及你，MySQL 数据库大小有上限，想装 Redis 缓存功能通常不给权限。用它做电商，等于用记事本写代码，能跑，但处处受限。

**轻量云服务器**是另一个极端：开箱即用，控制台选个 WordPress 或 WooCommerce 应用镜像，Nginx、PHP、MariaDB 都集成好了，半小时能出站。但产品限制是确实存在的：套餐是整体订阅模式，**无法横向扩容，流量突增只能升级整套规格**，不适合黑五这类超大并发的大促；大促场景有 CPU 积分耗尽导致卡顿的风险；地域选定后公网 IP 属地固定，实例生命周期内只支持自助更换 1 次公网 IP，IP 被拉黑基本只能重建实例；快照随实例释放一并删除，不能当数据库逻辑备份用。还有一条容易被忽略的：部分海外区域的轻量实例默认封禁 TCP 25 出站端口且不支持解封，发邮件必须走 465/587 端口配第三方 SMTP。

**VPS** 的核心优势就一句话：你说了算。root 权限在手，想装什么环境装什么，想开什么端口开什么，配置随用随调。代价是运维自己扛：系统更新、防火墙、SSL 续期、备份策略，都得自己安排。

一段取舍：如果你完全不想碰命令行，也没有大促级流量，轻量云的应用镜像能帮你省掉一整天；如果你要装对象缓存、改 PHP 内存上限、在同一台机器上跑多个站点，VPS 更合适。系统层面，建 WordPress 外贸站强烈建议选 Linux，Debian、Ubuntu、AlmaLinux 都行；Windows VPS 只适合必须跑 Windows 软件、远程桌面或 .NET 环境的场景，而且成本更高。

## 服务器到手之后，最短上线路径

1. **选系统**。Ubuntu 22.04 / 24.04 或 Debian 11 都行，LisaHost 是 KVM 架构，可选 CentOS、Ubuntu、Debian、RockyLinux、AlmaLinux。要 Windows 得提交工单让客服处理，官方建议至少 2 GB 内存以上。
2. **SSH 登录并更新系统**。付完款自动开通，几分钟内收到 IP 和 root 密码，`ssh root@你的IP`，然后 `apt update && apt upgrade`。
3. **装环境**。有 Linux 基础就手装 Nginx/Apache + PHP + MySQL；不想碰命令行就装宝塔或 1Panel，图形界面管 Nginx、PHP、MySQL。
4. **装 WordPress + WooCommerce**。主题选 Astra、Storefront 这类轻量的，插件能少装就少装，插件臃肿是后台变慢的头号原因。
5. **域名解析 + SSL**。A 记录指向服务器 IP，TTL 建议 600 秒，DNS 生效一般 2–48 小时；SSL 用 Let's Encrypt 加 Certbot，十分钟能配好，跨境电商没 HTTPS 等于直接劝退。
6. **防火墙**。放行 80 和 443，SSH 的 22 端口限制来源 IP 并改用密钥登录，**MySQL/MariaDB 的 3306 绝对不要对公网开放**。控制台防火墙和系统内部防火墙是串联关系，两层都要配。
7. **备份与加速**。快照用于版本回滚，但不能替代数据库逻辑备份，订单数据要单独定时导出到外部存储；跨洲访问配一层 CDN 加速商品图，商品量大、并发高时上对象缓存降低数据库压力。
8. **电商功能补齐**。多货币、多语言（WPML 或 Polylang）、PayPal 与 Stripe 加本地支付、运费规则与物流追踪、按销售地区配置税率。

## 什么情况下不该选 LisaHost

**退款有门槛。** 官网标的是 48 小时内不满意无条件退款，但实际条款里有流量限制：用超 20GB 或套餐流量的 5%（取小的那个）就不退；家宽 VDS 这类特殊产品只退到网站余额；USDT 付款也退到余额。这意味着你买完必须马上测，不能拖到第三天才想起来看。

**付款方式有限。** 只支持支付宝、支付宝备用通道和 USDT，没有信用卡，也没有 PayPal。公司账户走信用卡报销的，直接付不了款，这不是划不划算的问题。

**续费规则官网没写清楚。** 官网没有公开说明续费价和新购价是否一致。同类商家里“首年低价、次年翻倍”的做法并不少见，下单前值得开工单问一句，别默认年付会一直同价。

**部分产品组的国内访问体验不是卖点。** 新加坡、台湾、英国、越南、纽约、芝加哥这几组官网自己标了非大陆优化，国内直连 SSH 都可能卡，官方建议经香港或日本线路中转。如果你的日常工作流是天天登后台改价格、传图片，这几组会让你很难受。

**库存会变。** 美国 CN2 GIA 整组经常缺货，CERA 高防的精简档和基础档也常缺，日本原生 IP 基础版标着“特价限售 20 台”。看到合适的不一定马上能下单。

**低价档扛不住大促。** 1 核 1G 在平时够用，黑五这种瞬时并发上来，内存和 CPU 会同时见顶。做大促的店应该提前一档到 4 核 4G，或者干脆准备一台临时扩容机。

**你得自己运维。** 系统补丁、防火墙规则、SSL 续期、备份，全是自己的事。没有任何托管服务兜底。

**内容限制明确。** 官方禁止色情、赌博、诈骗钓鱼类站点，禁止散播病毒木马和攻击扫描；家宽 VDS 另禁垃圾邮件、群发、资源滥用，被发现或被投诉立即停机且不退款。

## 常见问题

**机房到底怎么选？**
看你的客户在哪，不看你在哪。北美客户选洛杉矶、圣何塞、纽约；欧洲客户选阿姆斯特丹、伦敦、法兰克福；亚太客户选香港、新加坡、东京。同时做两个市场又只买一台，选洛杉矶加 Cloudflare，别为了自己登后台快而牺牲客户体验。

**1 GB 内存能跑 WooCommerce 吗？**
能，但只能跑一个干净优化的站，内存占用要压在 600MB 以内，重型插件全禁。作长期生产环境不建议，2 GB 起步会省心很多。

**续费会涨价吗？**
官网没有公开说明续费与首购是否同价，没有任何公开资料能证实“续费同价”或“续费必涨”。下单前开工单问，比事后争论有用。

**要不要装宝塔面板？**
完全不懂命令行的建议装，图形界面管 Nginx、PHP、MySQL，建站门槛低很多。有基础的建议手装，少一层面板少一层攻击面和内存开销。

**一台服务器能跑几个独立站？**
4 GB 内存跑 2–3 个轻量 WordPress，6 GB 跑 3–5 个，8 GB 跑 5 个以上。多站点记得给每个站留足内存余量，别把 4 GB 塞满四个站。

**支持月付吗？还是只能年付？**
主力套餐都是月付，另有季付和年付特价档。想先试的走月付，确认速度和稳定性之后再考虑年付。

**能装 Windows 吗？**
可以，但不在自助安装列表里，需要提交工单让客服处理，官方建议 Windows 主机选 2 GB 内存以上，成本比 Linux 高。
